# Ritmo

Минималистичное Android-приложение напоминаний. Напоминания приходят как обычные
системные уведомления, созданные через точные будильники `AlarmManager`.

Текущий статус: **Этап 1** — однократные напоминания (настраиваемые повторения,
экспорт и импорт резервных копий, обновление через GitHub Releases появятся дальше).

## Возможности

- Создание однократного напоминания с точным временем срабатывания.
- Быстрый выбор времени: через 15 минут, через 1 час, завтра утром (09:00).
  Выбранный пресет помечается галочкой, подпись «Сработает» обновляется сразу.
- Список напоминаний с ближайшим срабатыванием и переключателем активности.
- Редактирование (нажатие на строку) и удаление (долгое нажатие) напоминаний.
- Точные системные уведомления (`setExactAndAllowWhileIdle`), открытие приложения по нажатию.
- Восстановление расписания после перезагрузки, смены времени/часового пояса и обновления APK.
- Тема оформления: системная, светлая или тёмная (переключатель в настройках, сохраняется между запусками).
- Настройки: выбор темы, компактные карточки разрешений («Уведомления», «Будильники») и проверка обновлений.
- Обновление из приложения: «Настройки» → «Обновления». Проверка идёт по запросу
  через GitHub Releases репозитория `tmksdm/ritmo`, сравнение по `versionCode`,
  скачивание только APK нужного релиза по HTTPS, установка системным установщиком.
  Фонового опроса нет.
- Локальное хранение в JSON во внутреннем каталоге приложения (запись через `AtomicFile`).
  Интернет используется только для проверки обновлений.

## Сборка

Требования: JDK 17, Android SDK с `platforms;android-35` и `build-tools;35.0.0`.

```sh
# путь к Android SDK можно указать в local.properties: sdk.dir=D:/path/to/android-sdk
export JAVA_HOME=/path/to/jdk17
./gradlew assembleRelease    # app/build/outputs/apk/release/app-release.apk
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
```

Release-сборка включает R8 и удаление неиспользуемых ресурсов.

## Подпись релизов

Все выпуски подписываются одним постоянным ключом — без него Android не позволит
обновить установленное приложение.

- Ключ: `D:\Pr\keys\ritmo-release.jks` (лежит вне репозитория).
- Параметры подключения: `keystore.properties` в корне проекта (в git не попадает).
- Если файла `keystore.properties` нет, release собирается с debug-подписью — сборка
  не падает, но такой APK нельзя установить поверх релизного.

Храните ключ и пароль к нему в надёжном месте: с их потерей обновления станут невозможны.

## Установка

```sh
adb install -r app/build/outputs/apk/release/app-release.apk
```

Или скопировать APK на телефон и открыть его (потребуется разрешить установку
из неизвестных источников).

## Версии

Схема версий: `ггмм.дд.номер`, где `гг` — год, `мм` — месяц, `дд` — день,
`номер` — порядковый номер сборки за этот день. Первая версия дня идёт без номера,
последующие — `2610.18.2`, `2610.18.3` и так далее.

Единственный источник версии — файл `version.properties` (в нём дата хранится как `ггммдд`).
Оттуда значение попадает и в `versionName` (`2610.18`), и в `versionCode`
(`ггммдд * 100 + номер`, то есть `26101802` — это даёт монотонный рост номера сборки).
Увидеть установленную версию можно в приложении: «Настройки».

Новая версия:

```sh
./gradlew newVersion        # 2610.18 -> 2610.18.2 -> 2610.18.3, в новый день снова 2610.18
./gradlew assembleRelease
```

## Разрешения

- `POST_NOTIFICATIONS` — показ уведомлений (Android 13+), запрашивается при первом запуске.
- `SCHEDULE_EXACT_ALARM` — точные будильники (Android 12+). Если доступ не выдан,
  приложение предупреждает об этом, а расписание становится менее точным.
  После выдачи доступа активные напоминания перепланируются в точном режиме.
- `RECEIVE_BOOT_COMPLETED` — восстановление расписания после перезагрузки.
- `INTERNET` — только проверка и загрузка обновления из GitHub Releases по запросу пользователя.
- `REQUEST_INSTALL_PACKAGES` — запуск системного установщика при обновлении.

`USE_EXACT_ALARM` не используется: он ограничен политиками распространения приложений.

## Обновление приложения

Проверка запускается вручную: «Настройки» → «Обновления».

1. Приложение запрашивает последний релиз репозитория `tmksdm/ritmo` через GitHub API.
2. APK релиза скачивается по HTTPS только если он относится к нужному репозиторию и релизу.
3. Перед установкой проверяются идентификатор приложения, подпись (должна совпадать
   с установленной) и `versionCode` (должен быть больше текущего).
4. Установку выполняет стандартный системный установщик с подтверждением пользователя.
5. Напоминания сохраняются: обновление ставится поверх приложения, данные не удаляются.

Фоновых служб и автоматической установки нет. Если Android не разрешает Ritmo установку
приложений, приложение предложит открыть соответствующий системный экран.

## Известные ограничения

- В режиме Doze и при агрессивной экономии батареи система может задержать срабатывание.
  Приложение не обходит системные ограничения.
- Если устройство было выключено в момент срабатывания однократного напоминания,
  пропущенное уведомление не восстанавливается (обработка пропусков — в Этапе 2).
