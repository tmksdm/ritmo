## Функциональность

- Расписания: однократно; интервалы (минуты/часы); ежедневно; еженедельно по дням недели;
  ежемесячно с переносом на последний день месяца; каждые N дней. Считаются по календарю
  (`Schedules.kt`). Окно интервалов — в пределах суток.
- Повторы планируются заново, дубли отсекаются, пропущенные не накапливаются; расписание
  восстанавливается после загрузки, смены времени и обновления APK. Переназначение будущего
  времени снимает признак завершения.
- Форма: тип повторения и параметры под него, числовые поля с цифровой клавиатурой;
  создание — кнопкой «Создать», при редактировании автосохранение со статусом «Сохранено».
- Резервные копии (`Backup.kt`): экспорт JSON через системный диалог сохранения
  (имя `ritmo-backup-ГГГГ-ММ-ДД.json`) и восстановление через системный выбор файла
  с проверкой до изменений и подтверждением замены. Запись — `AtomicFile`; после импорта
  старые будильники отменяются, новые планируются только на будущее.
- Интерфейс: плоские кнопки, контрастный основной текст, три режима темы, иконки Material,
  отступы от системных панелей, сортировка списка, меню действий.
- Обновление из приложения: релиз `tmksdm/ritmo` по запросу, сравнение по `versionCode`,
  проверка подписи, установка системным установщиком.
