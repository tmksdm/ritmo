## Что реализовано

Полные требования — в `PRODUCT.md`, здесь только фактическое состояние.

- Шесть видов расписания и необязательное окно времени суток для интервалов; расчёт по календарю
  (`Schedules.kt`). Повторы планируются заново, дубли отсекаются, пропущенные не накапливаются,
  расписание восстанавливается после перезагрузки, смены времени и обновления APK.
- Точные уведомления `AlarmManager` с разрешениями `SCHEDULE_EXACT_ALARM` и `POST_NOTIFICATIONS`;
  после выдачи доступа к точным будильникам активные напоминания перепланируются.
- Форма всех типов расписания: числовые поля с цифровой клавиатурой, создание кнопкой «Создать»,
  автосохранение при редактировании со статусом «Сохранено».
- Резервные копии (`Backup.kt`): экспорт и импорт JSON через системные диалоги, проверка файла
  до изменений, подтверждение замены, запись через `AtomicFile`, перепланирование после импорта.
- Интерфейс: плоские кнопки, контрастный текст, три режима темы, иконки Material, отступы от
  системных панелей, сортировка списка и меню действий.
- Обновление из приложения: релиз `tmksdm/ritmo` по запросу, сравнение по `versionCode`,
  проверка подписи, установка системным установщиком.
