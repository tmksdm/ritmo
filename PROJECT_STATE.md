## Состояние функциональности

- Расписания: однократно; через интервалы (минуты/часы); ежедневно; еженедельно по дням недели;
  ежемесячно с переносом на последний день месяца; каждые N дней. Считаются по календарю
  (`Schedules.kt`), а не от открытия приложения.
- Окно интервалов: по умолчанию выключено, отсчёт от начала окна, окончание окна допустимо при
  точном попадании на шаг. Окна через полночь не поддерживаются.
- После срабатывания повтор планируется заново, дубли отсекаются, пропущенные не накапливаются.
  Расписание восстанавливается после загрузки, смены времени и часового пояса, обновления APK.
- Переназначение будущего времени у сработавшего напоминания снимает признак завершения
  (`Reminder.reactivateIfRescheduled`); включить напоминание без будущего срабатывания нельзя.
- Форма: тип повторения и параметры под него; числовые параметры — компактные поля с цифровой
  клавиатурой. Новое напоминание добавляется кнопкой «Создать»; при редактировании работает
  автосохранение (название после паузы в вводе, параметры сразу после выбора) со статусом
  «Сохранено» и предупреждением при ошибке записи.
- Интерфейс: плоские кнопки, контрастный основной текст, темы системная/светлая/тёмная,
  иконки Material, отступы от системных панелей, сортировка списка, меню действий.
